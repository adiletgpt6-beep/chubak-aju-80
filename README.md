# Chubak Aju — детские уроки по акыде

Самостоятельный проект анимационных уроков на кыргызском языке для детей 4–12 лет. Не связан с репозиторием lesson-80.

## Пилот
- Источник: https://www.youtube.com/playlist?list=PLC-unxVGahSmS7NuDTU4m8L-9eEgCYMXa
- Ожидается 71 видео (подлежит автоматической проверке).
- Первая партия: первые 10 видео в порядке плейлиста.
- Итог: тематический каталог, расшифровки при наличии доступа, проверка источников, затем сценарий одного 60-минутного пилотного урока. Дополнительные уроки — только по объёму полезного материала.
- Вопросы имаму включать лишь если относятся к теме конкретного урока.
- Дословные защищённые материалы и исходные видео импортировать лишь при наличии соответствующего разрешения; знания, идеи и факты адаптировать в оригинальном изложении.

## Статус
Инициализирован репозиторий. Исходники не загружены, R2 не подключён, транскрипции не получены, сценарий не создан.

## План
1. Сформировать проверяемый реестр playlist/video ID, title, duration, URL, status.
2. Настроить повторяемый импорт новых плейлистов и предотвращение дублей.
3. Для разрешённых материалов настроить Cloudflare R2 через GitHub Secrets (без хранения ключей в репозитории).
4. Расшифровывать кыргызскую речь; отдельно маркировать вопросы, аяты, хадисы, утверждения, требующие проверки.
5. Создать тематическую карту и оригинальный сценарий для детей, согласовать религиозную точность.
6. Сделать пилотную анимацию, затем пакетное производство.

## Контроль качества
- Никаких вымышленных цитат и неподтверждённых хадисов.
- Сохранять источники и временные метки.
- Не использовать платные API и не запускать массовый рендер без согласования.
- Сохранять статус и следующие шаги в HANDOFF.md.
